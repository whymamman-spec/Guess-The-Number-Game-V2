# 🎯 Guess The Number Game (Version 2)

## Project Overview

This project is an improved version of the original Guess The Number Game developed during the 3MTT Software Development learning journey.

The application extends the basic game by introducing additional features that improve user experience and demonstrate more advanced JavaScript concepts.

Players attempt to guess a randomly generated number while receiving feedback and tracking their progress throughout the game.

---

## Project Scope

This version expands the original project by adding more interactive functionality and improving application flow.

The project includes:

* Random number generation.
* User input validation.
* Attempt tracking.
* Previous guess history.
* Game reset functionality.
* Keyboard support using the Enter key.
* Prevention of further guesses after the game ends.
* Use of Boolean values to manage game state.
* Preparation for future enhancements such as difficulty levels and score tracking.

---
